### 👋 Hi, I'm Anurag

I'm learning to build and ship real **AI applications** — and doing it in public. My days go into LLMs, prompting, RAG, agents, evals and fine-tuning, with every phase ending in a project that lands on this profile.

So far that's produced agents that query databases in plain English, a RAG pipeline that can read scanned documents, and a team of LLM agents that research a topic together. I also keep a daily AI news briefing so I know where the field is heading, not just where it's been.

Once the AI foundations are solid, I'm taking those agents off the screen and into the physical world through a long-term course in **robotics and embodied AI**.
